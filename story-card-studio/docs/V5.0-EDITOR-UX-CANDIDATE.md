# Story Card Studio v5.0 — editor usability development candidate

**Status:** Unreleased development branch; the owner-confirmed v5.0 on main remains unchanged pending a separate approval to promote.
**Source:** `../Story-Card-Studio-v5.0.html` in this branch; one standalone responsive HTML for desktop and mobile.

## Changes included

- JSON export from Story Card Editor accepts cards with empty **Keys/Triggers** and/or **Entry** values. The 5,000-card limit remains. Blank fields no longer cause an export-blocking error or spurious exact-duplicate confirmation for those incomplete records.
- Button labels:
  - Story Card Editor top controls: `↑ Download JSON for AID`, `↓ Add JSON to Editor`.
  - Merge left/right: `↓ Add JSON for First Set` / `↓ Add JSON for Second Set`.
  - Merge left/right source-from-editor buttons: `↓ Import from Editor`.
  - Merge center: `→ Send to Editor Tab`.
- **Editor scrolling:** The Story Cards heading, count, toolbar, Find & Replace controls and help text stay above an independently scrolling card board. The Card Details pane continues scrolling separately. At narrower responsive widths (930px and below), the existing document-scrolling layout is retained.
- **Type collapse:** Toggle each type's cards with a keyboard-focusable button in its header. Search temporarily reveals matching groups. Adding or dragging into a collapsed type reopens it so the card remains visible.
- **Merge collapse:** Independent left, right, and center Type headers can be expanded/collapsed without changing selections, source metadata or output order.
- Collapse state is **local to the active page session**, not stored in exported JSON or written into creator-owned cards.

## Acceptance checklist before main promotion

1. Download the raw full HTML from this development branch; open it in Chromium/Safari.
2. Create cards with blank Keys, blank Entry, and both blank; export and reimport to verify no fields or custom properties were lost.
3. Load a 5,001-card dataset and confirm the existing maximum blocks export.
4. Scroll a dense card board on desktop; title, toolbar, counts, help text remain stationary while Card Details scrolls independently.
5. Collapse/expand each Type in stacked and columns arrangements. Search for a card in a collapsed type, add a new card, and drag a card into a collapsed type. Check desktop and mobile layouts.
6. On Merge JSONs, load separate collections, collapse Types independently in First Set, Second Set, and center; verify selections, export, and editor transfer remain unchanged.
7. Confirm all button labels exactly; verify the arrow semantics match the destination described.
8. Repeat at mobile width and check full-screen details, Find & Replace controls, and touch drag.
