## Checklist before the next approved code change / deployment

1. Open HTML, check version/title; import and export real JSON preserving custom properties.
2. Test Story Card edit, move by Type, bulk mode, delete/Undo, stacked/column views, right-rail details, and optional RE Acts.
3. Test Find & Replace Next/Previous, single and confirmed bulk replacement, restricted Title/Keys/Entry/Notes scope, preset row edits and storage behavior.
4. Merge two collections, choose from both, export/import combined data and verify exact fields.
5. Trigger Analysis: warnings, reference network, pasted story-text results and approximate token descriptions.
6. RE OFF: Demo Cards, hidden RE tabs, ordinary-editor parity.
7. RE ON: 24-card fixture, six per Act; six overview metrics; highlight/color keys; charts, rarity/importance/duration settings, and RE Config/Advanced cards. **Chart scale regression:** move 12 encounters to Act 1, leave other encounters in Act 2, then add at least 120 non-RE cards; verify Act Structure and Encounter Spread bar axes stay encounter-only, with identical chart scales before and after adding the ordinary cards.
8. Inner Self and Auto-Cards: create/open/hide config cards without duplicates; preserve settings on export.
9. Mobile: picker navigation, full-screen Card Details, scrolling, touch-drag cancel/no-op/auto-scroll, keyboard, export. Repeat on **real Safari** rather than treating emulation as equivalent.
10. For GitHub Pages publication, check the Actions checksum gate and deployment status, then verify the served app title/version, direct URL and imported/exported JSON behavior. No third-party hosting path is part of the current workflow.

Always record branch, commit, artifact SHA, device/browser, result and any NOT RUN checks.
