## v5.1 behavior changes

- Story Card Editor JSON download permits blank Keys/Triggers and Entries, singly or together. The maximum 5,000 cards remains enforced, and arbitrary imported properties remain protected.
- Clearer toolbar labels: **Upload JSON to Studio**, **Download JSON for AID** (no arrow); Merge **↓ Add JSON for First Set**, **↓ Add JSON for Second Set**, **↓ Add Cards from Editor**, **→ Send to Editor Tab**.
- Left editor pane pins the Story Cards heading, total, toolbar, Find & Replace controls and help text while the card board scrolls independently on desktop. Existing mobile document scrolling is retained.
- Collapsible Type groups in the Editor and all three Merge columns, with state isolated from exported JSON. Dragging or adding a card into a collapsed Type reopens it; searching temporarily exposes matching Types.
- Merge First/Second Set **Deselect All** removes selections but preserves their loaded cards. A separate **Clear** for each source removes that source's cards after confirmation. The center **Clear** removes the merged selection after confirmation but preserves both source sets. Canceling does not mutate data. Controls disable when their respective column is empty.
