## Encounter chart-scale correction — 2026-10-21

The canonical v5.0 HTML now uses `encounterCardAxisMax(counts)` for the numeric Y-axis maximum in **Act Structure** and the **Encounter Spread** stacked bar chart. Both helpers explicitly filter `RAND_##` encounter cards before computing counts. With 12 encounters in an Act, the Y-axis maximum is 12 instead of the prior 40. The axis rounds up to a nearby multiple of four (minimum 4), preserving integer-spaced quarter ticks.

**Fresh verification:** the same 18 encounter cards produced byte-identical chart SVGs before/after adding 120 ordinary Story Cards at Chromium viewport widths 1440, 768 and 390px; no JavaScript page errors. The inline JavaScript passed Node `--check`. This is targeted chart verification, not a full fresh regression, AI Dungeon or physical iOS Safari pass.

## Storage and release boundaries

The standalone editor processes data locally. Export JSON for durable backups; do not rely on `file://` browser storage or iOS caches. v5.0 uses the established desktop workspace key; older mobile workspaces require export/import migration.

A commit to the canonical HTML on `main` triggers the checksum-gated GitHub Pages workflow; verify the resulting Actions run and served content independently. No external hosting provider is part of the ongoing process, and a public Release or tag remains separately authorized. The old PWA distribution plan is still a proposal: an installable offline-first PWA is not yet implemented.
